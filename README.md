# Uber-Interactive-Dashboard
1. Project Title
   
•	Uber Interactive Dashboard

2. Description
   
•	An interactive dashboard created using Microsoft Power BI to analyze Uber ride data.
•	The dashboard consists of 2 pages (Home & Overview) and allows users to switch between vehicle types (Auto, Bike, etc.) using icons, dynamically updating all visuals.

3. KPIs
   
•	Completed Bookings
•	Lost/Cancelled Bookings
•	Revenue
•	Total Distance
•	Average Distance

4. Visuals Included
   
•	Booking trend (Month / Quarter line chart)
•	Revenue bar chart
•	Revenue by vehicle type
•	Ride status (Completed, Cancelled, Incomplete)
•	Customer & Driver Ratings
•	Top Pickup & Drop Locations

5. Key Feature
   
•	2-page navigation: Home & Overview
•	Interactive vehicle icons for dynamic filtering
•	Dashboard updates based on selected vehicle type

6.Insights

•	Booking trends vary across months
•	Revenue differs by vehicle type
•	Certain locations have higher pickups/drops
•	Ratings remain consistent
